How it works: This is a 536K-parameter KAN (Kolmogorov-Arnold Network) language model trained on 20,000 chess games. It has a Hopfield memory cache (32 stored opening patterns), predictive coding (each layer predicts the next), gated spline activations (learnable per-neuron functions), and temperature annealing.

The brain generates PGN text character-by-character. It doesn't evaluate positions — it predicts the next character in a chess game transcript, like autocomplete for chess.
